# v6-2026-10-11 导入和导出 Profile

## 目的

提供可迁移的 Profile JSON 备份，方便在不同部署之间复制订阅设置、转换脚本和文本追加项。

## 主要改动

- 管理页“当前 Profile”行新增“导入”和“导出”，并将它们放在这一行最右侧；下方操作行保留新建、复制、重命名和删除。
- 导出当前 Profile 为 JSON，包含显示名称、上游设置、请求头、更新间隔、转换脚本和文本追加项。
- 导入备份时可编辑 Profile ID 和显示名称，并创建为新的 Profile；已存在的 ID 不会被覆盖。
- 备份不包含缓存、错误信息和拉取历史；导入时重新生成脚本和追加项的内部 ID。
- 服务端新增 Profile 导出接口和导入接口，并对备份格式、设置、脚本和追加项执行完整校验。
- 页面提示导出文件包含上游链接和请求头等敏感设置。
- 导入文件选择器保持隐藏，只由“导入”按钮触发，避免原生文件控件挤占 Profile 操作栏。
