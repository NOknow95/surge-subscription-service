# v1-2026-10-09 完善脚本接口、管理页编辑器和本地运行配置

该组改动已并入初始提交（2026-10-09）。

## 目的

简化脚本编写方式，减少脚本对 `sections` 包装的依赖；提升管理页脚本编辑器的可用性；提供随镜像发布的脚本编写指南；把服务与 Docker 的默认端口调整为 3080，并支持本地只绑定回环地址试用。

## 主要改动

### 脚本接口

- 配置对象改为可直接按分节名访问：`config['General']`、`config['Proxy Group']`、`config['Rule']` 等，值为行数组。
- `config.rules` 保留为 `[Rule]` 的便捷入口，与 `config['Rule']` 指向同一数组，读取、赋值、删除行为一致。
- 脚本只需返回配置对象；返回对象中名为 `rules` 的分节会写回 `[Rule]`。异步脚本仍不支持，每个脚本仍限制 500 毫秒；`node:vm` 不作为安全隔离边界。

### 解析与输出

- 脚本读取到的分节数组不含空行（解析时过滤）；未修改的分节按上游原文输出，保留原有注释、内部空行和行顺序（`[Rule]` 顺序不受影响）。
- 修改过的分节按脚本给出的数组输出并过滤空行；相邻分节之间统一保留一个空行。

### 脚本语法校验

- 新增 `POST /api/scripts/validate`：只解析语法，不保存、不执行脚本。
- 保存脚本（新增与更新）时同样先做语法校验。
- 语法错误返回 `脚本「名称」语法错误（第 X 行，第 Y 列）：...`，行列位置取自解析错误位置。

### 管理页编辑器与预览

- 代码区增加行号栏，与文本框滚动同步。
- Tab 插入两个空格；选中多行时 Tab/Shift+Tab 批量增减缩进；Shift+Tab 也可删除行首缩进。
- Enter 延续当前行缩进，在 `{`、`[`、`(` 后自动增加一级缩进，输入对应的 `}`、`]`、`)` 时按缩进回退。
- 查找面板：按钮或 Cmd/Ctrl+F 打开，显示匹配计数，Enter/Shift+Enter 或按钮上下跳转，Esc 关闭；打开时可使用选中文本作为关键字。
- 自动换行开关，默认关闭、可切换。
- 其他调整：提示改为可关闭、重复计数并自动消失的顶部浮层；上次成功配置支持行号显示、刷新和复制；上游链接可切换显隐；状态文案区分「未配置上游」。

### 脚本编写指南

- 新增 `public/script-guide.html`，随 Docker 镜像发布，并注册静态路由 `/script-guide.html`；管理页与 README 均提供入口。

### 上游体积限制

- 上游配置体积上限由 5 MB 提升到 15 MB（Content-Length 与流式累计两处检查）。

### Docker 与端口

- 服务默认端口由 3000 改为 3080，`src/server.js`、Dockerfile 的 `ENV PORT`/`EXPOSE` 与 compose 环境变量保持一致，管理页对外访问地址占位提示同步更新。
- `compose.yaml` 端口映射改为 `${HOST_BIND:-0.0.0.0}:3080:3080`，可用 `HOST_BIND=127.0.0.1` 只绑定回环地址。
- README 将部署章节改写为「Docker 本地试用」，说明回环绑定方式、`http://127.0.0.1:3080` 访问地址、日志命令和公网暴露风险；脚本接口文档更新为按分节名直接访问与 `config.rules`，并加入脚本指南入口。
