# v4-2026-10-10 文本追加配置

## 目的

增加无需编写 JavaScript 的配置行追加方式，便于直接向 Surge 指定分节添加文本。

## 主要改动

- 管理页新增“文本追加”，每项可指定分节名、插入最前或最后的位置，以及多行配置文本；支持编辑、启用/禁用、排序和删除。
- 追加项增加必填名称（1–100 字符），表单按“名称、分节名、插入位置”三列排列，窄屏依次换行。列表显示名称及分节、位置等信息；已有无名称追加项自动以“分节名 · 插入位置”补名称，无需手动迁移。创建追加项的 API 请求需提供 `name`，更新时可省略以保留原名称。
- 对外访问地址的占位示例使用当前页面来源地址，避免固定端口示例与实际服务端口不一致。
- Profile ID 允许首个小写字母之后包含数字，例如 `test1`；保留 1–16 字符限制，前后端校验及页面提示同步更新，已有 ID 无需迁移。
- 追加项在转换脚本执行前按列表顺序应用。每项可控制“分节不存在时创建”，默认勾选，已有追加项保持自动创建；取消勾选时遇到缺失分节则跳过该项，已有空分节或前面的追加项已创建的分节仍正常追加。API 使用布尔字段 `createIfMissing`，省略时沿用原值或默认 `true`。首尾空行会裁掉，中间空行保留。
- 追加项按 Profile 保存，复制 Profile 时一并复制。新增 `/api/profiles/:id/appends` 管理接口，支持创建、更新、删除和调整顺序。
- 修改过的分节会输出追加结果，分节内的空行按配置内容保留。
- 增加“完全覆盖分节”选项，默认关闭，旧数据保持追加行为。勾选后隐藏插入位置，用文本替换目标分节全部内容（包括前面项目写入的内容）；关闭后恢复原插入位置。缺失分节仍受创建选项控制，后续项目及脚本继续按顺序执行。API 使用布尔字段 `overwrite`，省略时沿用原值或默认 `false`。
- 追加文本编辑框增大默认高度，随窗口高度调整（最小 280px，默认最多 420px），并支持手动拖动调整高度。
- 插入位置改用与 Profile 选择器一致的自定义菜单，统一选中态、圆角和阴影，支持方向键、Home/End、Enter/Space、Esc 和 Tab 操作。
- 追加文本编辑器提供行号、查找及自动换行；支持匹配计数、上一个/下一个、Cmd/Ctrl+F、Enter/Shift+Enter 和 Esc。行号随输入、滚动和窗口尺寸变化同步更新，自动换行仍按原始配置行编号。
- 脚本与追加文本编辑器共用行号渲染及栏宽计算，行号栏至少预留三位、左右各留 4px，超过三位时自动扩宽；两者统一默认高度、最小高度和拖动调整方式，在自动换行和尺寸变化时同步行号高度。
