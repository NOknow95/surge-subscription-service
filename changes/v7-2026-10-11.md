# v7-2026-10-11 导入到 Surge

## 目的

在管理页直接把当前 Profile 的托管配置链接交给 Surge，减少复制和切换应用的操作步骤。

## 主要改动

- 在“复制链接”右侧新增“导入到 Surge”按钮。
- 点击按钮后使用 `surge:///install-config?url=...` URL Scheme 打开当前 Profile 的订阅链接。
- URL 参数使用百分号编码，并沿用当前 Profile 实际生成的订阅链接。
- Profile 尚未加载完成时按钮保持禁用；“复制链接”继续作为备用方式。
- “复制链接”点击后先使用现代剪贴板接口，失败时自动尝试兼容复制方式；两种方式都失败时才提示手动复制。
- 管理页标题版本号更新为当前 v7 变更版本。

- 已通过 `node --check public/app.js`。
