# v5-2026-10-11 刷新后保留当前 Profile

## 目的

修复切换到其他 Profile 后刷新管理页会自动回到 `default` 的问题。

## 主要改动

- 管理页把最近选择的 Profile ID 保存到浏览器本地存储，刷新后优先恢复该 Profile。
- 如果已记录的 Profile 已被删除，则回退到 `default`；没有 `default` 时使用第一个可用 Profile。
- 保存文本追加项后保持编辑器展开，并回填服务端保存后的内容，方便连续修改同一条追加项。
- 保存转换脚本后，成功提示提供“立即拉取并转换”按钮，点击后刷新当前 Profile 的配置。
- 文本追加和转换脚本编辑器在标题行增加小尺寸“保存”和“收起”按钮，保留底部操作；转换脚本标题行同时提供“检查”，与底部按钮共用检查逻辑和忙碌状态。“取消”改为“收起”，保存及检查按钮文案统一简化为“保存”和“检查”。

## 浏览器标签图标

### 目的

为管理页和脚本编写指南页补充浏览器标签图标，便于在多个标签之间识别本服务。

### 主要改动

- 新增本地 `public/favicon.svg`，使用绿色主题和节点连线图形，作为 Surge 订阅代理的标签图标。
- 管理页和脚本编写指南页通过 `<link rel="icon">` 引用该图标。
- HTTP 静态资源路由新增 `/favicon.svg`，确保浏览器可以直接访问图标。

### 验证

- 已检查两个 HTML 页面均引用 `/favicon.svg`。
- 已检查服务端静态资源映射包含 `/favicon.svg`，响应类型为 `image/svg+xml`。

## 管理页显示版本号

### 目的

在管理页标题区域显示当前变更版本，方便通过浏览器页面直接确认部署版本。

### 主要改动

- 在“订阅代理”标题右侧显示 `v5-2026-10-11`。
- 使用低对比度的小字号样式；窄屏空间不足时允许版本号换到下一行，保留状态标签和标题的视觉层级。

### 验证

- 已检查管理页标题区域包含 `v5-2026-10-11`。
